## Что реализовано
- Запрос имени пользователя через `prompt` и вывод приветствия в `alert`.
- Хранение данных о видимой звездной величине объектов в массиве.
- Функции для поиска минимума (самого яркого объекта), фильтрации массива и подсчета суммы элементов.
- Фильтрация ярких объектов со звездной величиной меньше 3m и подсчет общей средней яркости.
- Поиск через цикл тусклых объектов (5m и выше), подсчет их количества и средней яркости с выводом результатов в `console.log`.
- Проверка дополнительного условия: если минимальное значение в массиве меньше или равно -2m, в консоль выводится предположение о том, что среди объектов есть планеты.
